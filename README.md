## 🚀 How to Run & Preview

### Option A: Double-Click
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari). No build steps or servers required.

### Option B: Local Server (Python)
If you want to run a local server:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080` in your browser.
